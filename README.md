# Seq2Seq-Question-Answering-System
# 🤖 NLP Question Answering Chatbot

An intelligent chatbot that answers user questions using Natural Language Processing (NLP) techniques.

This project uses a Retrieval-Based approach where the chatbot finds the most similar question from the dataset and returns the correct answer.

---

## 🚀 Features

- Understands user questions
- Returns accurate responses
- Fast and lightweight
- Works with small dataset
- Simple Flask web interface

---

## 🧠 How It Works

1. User enters a question
2. Text converted to numerical vectors using TF-IDF
3. Cosine similarity finds closest match
4. Corresponding answer returned
